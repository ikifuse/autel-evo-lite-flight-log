# autel-evo-lite-flight-log

EVO Lite / Lite+ 向けの、航空法第132条の88（飛行日誌の作成・携行・保管義務）に完全準拠した運航記録・点検・整備・バッテリー管理Webアプリケーションです。

現在のバージョンは「**ドローン運航記録 v14 入力支援・エラー明示＆完全復旧版**」です。

---

## 1. このプロジェクトを作った理由

ドローンスクールでの実技講習修了後、独学や通信講座で法令や実運用を学びながら国家資格（一等・二等無人航空機操縦士）を取得・運用するにあたり、以下の課題を手探りで解決するために開発されました。

- **法律上の必須記録を1つも落としたくない**（特定飛行における10万円以下の罰則リスクを排除）
- **現場では文字入力を極力排除したい**（手袋着用や日光下でもワンタップ・GPS・ストップウォッチで完結）
- **入力漏れやミスがあっても、どこを直せばいいか一目でわかるようにしたい**（未入力項目の箇条書き明示＆赤枠ハイライト）
- **途中で中断した記録があっても迷わず「再開」か「破棄」を選べるようにしたい**
- **過去の履歴やお気に入り現場を1秒で呼び出したい**
- **許可承認の期限切れや補助者の記録漏れを未然に防ぎたい**
- **山間部など電波の届かない現場でも、警察官や監督官に即座に提示できるようにしたい**

## 2. 実装されている機能一覧

### ① 入力支援・エラー視覚化 ＆ セッション復旧（迷いゼロ設計）
- **未入力項目の具体的箇条書き表示**：「【機体】【飛行経路・場所】が入力されていません」と明示
- **入力欄の赤枠ハイライト & 自動フォーカス**：抜けている欄に赤枠がつき、即座に修正可能
- **中断セッションの親切案内 & ワンタップ復旧**：前回の記録が残っている場合、機体名・進捗状況を表示し「続きから再開」または「破棄して新規開始」をワンタップ選択可能

### ② 飛行記録（様式1準拠・現場自動化）
- EVO Lite / EVO Lite+ の機体自動識別（登録記号：JU3268805C02 / JU3269B165D2）
- **GPSワンタップ位置取得（逆ジオコーディング）**：現在地から都道府県・市区町村・緯度経度を自動取得
- **直前履歴の1タップ引用 & お気に入り現場プリセット**：1タップで前回設定や主要現場を即座にセット
- **ストップウォッチ式リアルタイム計時**：離陸ボタンで秒単位カウント、着陸ボタンで飛行分数を自動算出
- 飛行目的（18種類＋その他詳細入力）
- 飛行禁止空域・飛行方法（DID、夜間、目視外、人・物件30m未満等の複数選択）
- 飛行カテゴリー（カテゴリーⅠ／Ⅱ／Ⅲ）の自動判定・連携
- 離着陸時刻の自動取得、実飛行時間（分）の自動計算
- **機体ごとの総飛行時間（累計飛行時間）の自動積算・記録**
- **安全影響事項クイックタグ選択**（突風、鳥の接近、電波微弱、GPS遅延、発熱、なし等）
- **機長（操縦者）と補助者の分離記録**

### ③ 行政・監査対応（防壁機能）
- **国土交通省 許可・承認書番号連動**（東空運/阪空運番号の保持）
- **許可期限切れアラート（30日前黄色警告、期限切れ赤色アラート）**
- **オフライン提示用PDF出力**：当日の飛行日誌（A4横向き）を即座にダウンロード可能。電波ゼロの現場でも提示義務を達成。

### ④ 日常点検記録（様式2準拠）
- **飛行前点検（11項目）**：「全て正常」一括チェックボタン、異常検知時の特記事項入力と安全飛行停止制御
- **飛行後点検（4項目）**：機体・プロペラ・発熱・その他の良否判定
- 不具合箇所、事象の内容、是正処置内容、確認者氏名の記録

### ⑤ 点検整備記録（様式3準拠）
- 定期点検、プロペラ等の部品交換、修理、改造、ファームウェア更新の専用入力
- **点検整備実施時点での機体総飛行時間を自動算出・自動記入**
- 交換部品名、実施理由、合否判定、次回点検予定時期の管理

### ⑥ 信頼性・データ保護
- **自動下書き保存（LocalStorage）**：電話着信やリロードでも消えずに入力復元。送信完了で自動クリア。
- **改ざん防止・監査ログ（記録訂正機能）**：誤入力時の修正内容・訂正理由・日時・実行者を「訂正履歴」シートへ自動保管。
- **バッテリー個別管理（7本）**：BAT_1〜7の使用履歴、実飛行時間、サイクル数、所感を個別追跡。
- **二重送信・競合防止**：GASのスクリプトロック機能（LockService）による安全な排他制御。

## 4. 運航の流れ（迷わない最短3ステップ）

1. **運航開始**：機体を選び、飛行前点検を「全て正常」でワンタップ完了。
2. **飛行・着陸**：バッテリーを選んで「離陸」。着陸後に「着陸を記録」。
   - バッテリー交換時は「バッテリー交換して続ける」で連続飛行。
3. **運航終了**：飛行後点検を「全て正常」で確認して完了。「PDF表示」で日誌を端末に保存。
