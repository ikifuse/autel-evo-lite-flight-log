# AUTEL EVO Lite / Lite+ ドローン運航記録システム
（国土交通省 飛行日誌 完全適合・完全無料・オフライン対応 Webアプリケーション）

航空法第132条の88（無人航空機の飛行日誌の作成・携行・保管義務）に完全準拠し、現場での安全運航と最速記録を両立させるために開発されたGoogle Apps Script（GAS）ベースのWebアプリケーションです。

追加費用や有料APIは一切使わず、Googleアカウント（無料）のみで動作します。

## 🚀 主な特徴と現場最適化機能

### 1. 完全オフライン耐性（山間部・海岸等の電波圏外対応）
* **現場作業を1秒も止めないオフライン進行**：山奥や海上などの電波圏外でも、エラーで画面が止まることなく「運航開始」「飛行前点検」「離陸」「着陸」「機体交代」「飛行後点検」を最後までスムーズに記録できます。
* **ローカル安全キューイング**：通信できない間のデータは端末（LocalStorage）の安全なキューに一時保存されます。
* **電波復帰時のワンタップ一括同期**：電波が繋がった際に「🔄 今すぐ同期」を押すだけで、溜まったデータが順番にスプレッドシートへ自動反映されます。
* **電波状態＆未同期件数バッジ**：画面上部に「● オンライン / ● 圏外」「📦 未同期: X件」がリアルタイム表示されます。

### 2. 気象情報（天候・風速・風向）のワンタップ入力
* 航空法および標準飛行マニュアルで求められる気象確認を、現場で手打ちすることなく親指ワンタップで入力可能。
  * **天候**：`[晴]`, `[曇]`, `[雨]`, `[強風注意]`
  * **風速**：`[0〜1m/s 静穏]`, `[2〜3m/s 穏やか]`, `[4〜5m/s 注意]`, `[6m/s以上 飛行不可]`
  * **風向**：`[北]`, `[北東]`, `[東]`, `[南東]`, `[南]`, `[南西]`, `[西]`, `[北西]`
* 入力データは「飛行目的（飛行概要）」セルの末尾に自動結合され、**スプレッドシートのA4印刷レイアウトを1ミリも崩さず記録**されます。

### 3. 2機交互運航（Lite ↔ Lite+）のスムーズな機体交代
* 機体の熱対策やバッテリー運用のために日中に機体を切り替える際、着陸後画面の **[ 🔄 もう1機の機体に交代する ]** ボタンで即座に切り替え可能。
* 朝入力した現場情報（場所・操縦者・目的等）は自動引き継ぎされ、無駄な再入力がありません。

### 4. 夕方の「飛行後点検」スマートまとめ（現場実務100%準拠）
* フライトの合間にいちいち点検を強制されるストレスを排除し、撤収時に**「本日実際に飛ばした機体だけ」**をまとめて飛行後点検できます。
* 最上部の **[ ✨ 本日使用した全機体「全て正常」 ]** ボタンで1秒で点検完了し、即座にその日の日誌が確定します。

### 5. 午前・午後・複数現場の移動に対応（自動連番シート）
* 1日に複数箇所（午前と午後など）を移動して運航する場合、トップ画面の **「🏢 本日別の新しい現場として連番シートで開始する」** を選ぶことで、`2026.9.4_2`、`2026.9.4_3` と別シートが自動生成され、独立した日誌として提出・管理できます。

### 6. 法定3大記録の完全網羅
* **飛行記録（様式1）**：離着陸場所・時刻、実飛行時間、総飛行時間の自動積算、安全影響事項
* **日常点検記録（様式2）**：飛行前11項目、飛行後4項目、異常時の特記事項・処置内容
* **点検整備記録（様式3）**：定期点検、部品交換、修理、合否判定、次回点検予定時期

### 7. 行政・監査対応（防壁機能）
* **国土交通省 許可・承認情報**：東空運/阪空運番号の保持、期限切れ30日前警告＆期限切れ赤色アラート
* **オフライン携行用PDF出力**：山間部など電波のない現場でも、警察官や航空運航安全監督官に即座に提示できるA4横向きPDFを端末へ即時表示・ダウンロード可能。

## 📱 運航の流れ（迷わない現場最短ルート）

1. **現場到着（朝）**：
   * 現場情報、気象情報（晴・風速・風向）を選択。
   * 飛行前点検を「全て正常」でワンタップ完了。
2. **飛行・着陸（日中）**：
   * 使用バッテリー（BAT_1〜7）を選んで離陸。
   * 着陸後、プロペラ停止を確認してから飛行時間（分）を入力して着陸記録。
   * 「バッテリー交換して続ける」または「もう1機の機体に交代」でスムーズに連続運用。
3. **撤収（夕方）**：
   * 「本日の全運航を終了」を押し、本日飛ばした機体の飛行後点検をワンタップ「全て正常」で完了。
   * 完成したA4日誌PDFを表示・端末保存。
