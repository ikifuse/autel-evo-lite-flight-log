# autel-evo-lite-flight-log

EVO Lite / Lite+ 向けの、飛行記録・点検・整備・バッテリー管理をまとめて行うための個人用Webアプリ試作品です。

現在のバージョンは「ドローン運航記録 v11 4機能実装版」です。

## このプロジェクトを作った理由

私はドローンスクールには通いましたが、実際には実技中心で、座学や実運用についてはドロビーの通信講座や独学で学んでいます。

もともとはおもちゃのドローンを少し飛ばすつもりでしたが、情報収集不足のまま国家資格を取る流れになり、現在も機体選び・保険・申請・飛行記録・点検などを手探りで進めています。

分からないことをAIに相談しながら、最初はExcel / Googleスプレッドシートで記録表を作るつもりでした。

しかし、

- 自分でも迷わず入力できるようにしたい
- 必要な記録を落としたくない
- 普段は入力をできるだけ少なくしたい
- 分からない任意項目は空欄でも進めたい
- 異常や不具合がある時だけ詳しい項目を出したい

という相談を続けているうちに、結果としてGoogle Apps ScriptのWebアプリのような形になりました。

## 現在できること

- EVO Lite / EVO Lite+ の機体選択
- 飛行前点検
- バッテリー交換を挟む同一条件の連続飛行をまとめた飛行記録
- 同じ機体で継続 / 機種変更 / 当日の運航終了の分岐
- 飛行後点検
- バッテリー7本の個別記録と実飛行時間の集計
- 点検・整備・修理・部品交換記録
- 機体ごとの累計飛行時間管理
- 日付・機体別の飛行前 / 飛行後日誌シートの自動作成
- 今日の飛行日誌をPDFで即時表示
- 日付・機体による過去の飛行日誌検索
- 保存済みの飛行記録・バッテリー記録の訂正と訂正履歴の保存
- 入力途中の内容をブラウザへ自動下書き保存・復元
- 保存済みの運航状態へ戻れる操作UI
- 処理中の操作無効化とスクリプトロックによる二重送信・二重保存対策
- 操縦者の変更（普段は吉田公一を初期値にし、必要時のみ他の操縦者へ変更）

## 操作方針

このアプリは、できるだけ「何をすればいいか迷わない」ことを優先しています。

通常時は必要な項目だけを表示し、任意項目は空欄でも進められるようにしています。一方、異常や不具合がある場合は追加情報を求める設計にしています。

また、飛行前点検で異常がある場合は、そのまま飛行開始できないようにしています。

## まだ試作品です

このプロジェクトは、実務経験者やメーカー公式の設計ではありません。

私は現在も独学で実運用を学んでいる段階なので、

- こんな飛行記録でよいのか
- 足りない項目はないか
- 逆に不要な項目はないか
- 実際の現場ではもっと簡単にできる部分がないか

などについて、実務経験のある方からの指摘や改善提案を歓迎します。
